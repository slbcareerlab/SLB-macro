# SLB macro

웹게임 「이번 생은 야구다」(slbcareer.com)용 매크로입니다. 태생 리세와 반자동 육성(특별훈련 대신하기)이 하나의 패널에 들어 있습니다.

## 파일

| 파일 | 용도 |
|---|---|
| `loader.user.js` | **기기에 설치하는 것.** 게임 페이지를 열 때마다 `main` 갈래의 최신 매크로를 받아 실행합니다. |
| `loader-test.user.js` | 테스트용. `dev` 갈래(출시 전 버전)를 받아 실행합니다. 패널 제목에 `[테스트]`가 붙습니다. |
| `slb-macro.user.js` | 매크로 본체. 불러오기가 받아 가는 파일입니다. 직접 설치해도 동작합니다. |

## 설치

1. 기존에 설치한 매크로(`이생야 통합 매크로`, `SLB 태생 리세 매크로` 등)는 끄거나 지웁니다. 두 개가 켜져 있으면 먼저 실행된 쪽만 돌고, 그게 옛 버전일 수 있습니다.
2. `loader.user.js`를 열고 **Raw** 버튼을 눌러 설치합니다.
   - 아이폰·아이패드(Safari + Userscripts 앱): Raw 화면에서 Userscripts 확장 아이콘을 눌러 설치합니다.
   - 안드로이드(Firefox + Tampermonkey/Violentmonkey): Raw 화면에서 설치 화면이 뜨면 설치를 누릅니다.
3. 게임 페이지를 새로고침하면 패널이 뜹니다. 패널 아래 `v1.00`처럼 버전이 보입니다.

## 업데이트

- 새 버전은 먼저 `dev` 갈래에 올라옵니다. 이때 기기의 매크로는 바뀌지 않습니다.
- 확인할 때는 `loader.user.js`를 끄고 `loader-test.user.js`를 켠 뒤 새로고침합니다. 확인이 끝나면 다시 반대로 바꿉니다. **둘을 동시에 켜지 마세요.**
- 확인이 끝나 `dev`를 `main`에 합치면(출시), 모든 기기에서 새로고침만 하면 새 버전이 됩니다. GitHub 캐시 때문에 최대 몇 분 늦을 수 있습니다.
- 인터넷이 안 되거나 받기에 실패하면, 이 기기에 저장된 마지막 버전으로 실행하고 화면 위에 안내가 뜹니다.

## 주의

- 게임 이용약관 제6조는 자동화 프로그램 사용을 금지합니다. 계정 제재 위험을 감안하고 쓰세요.
- 이 저장소에 코드를 올릴 수 있는 사람은 게임에 로그인된 페이지에서 그 코드를 실행시킬 수 있습니다. GitHub 계정은 2단계 인증으로 지키세요.
